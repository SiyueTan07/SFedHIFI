palette (Okabe-Ito or Paul Tol) and ensure black-and-white readability.

## Generation recipe (suggested)

1. After running each experiment script under `paper/scripts/`, the logs are
   written to `experiment/<save_name>/log.txt` with per-round accuracy and
   sparsity statistics.
2. A separate `paper/figures/scripts/` directory should hold the matplotlib
   plotting scripts that consume those logs. (Not yet checked in; create as
   needed.)
3. Recommended matplotlib settings:
   ```python
   import matplotlib.pyplot as plt
   plt.rcParams.update({
       'font.family': 'serif',
       'font.size': 9,
       'axes.linewidth': 0.6,
       'lines.linewidth': 1.4,
       'pdf.fonttype': 42,  # editable text
       'ps.fonttype': 42,
   })
   ```
4. Always export with `bbox_inches='tight'` and `pad_inches=0.02`.
